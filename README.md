TaskFlow — Система обліку домашніх завдань і дедлайнів. Вебзастосунок для централізованого обліку, моніторингу та управління домашніми завданнями для студентів/учнів та викладачів. Допомагає оптимізувати навчальний процес і запобігає зривам термінів виконання робіт.

Основний функціонал
- Каталог завдань: Додавання, редагування та фільтрація завдань за предметами й пріоритетом.
- Трекінг дедлайнів: Візуальний календар та сповіщення про наближення кінцевих термінів.
- Статуси виконання: Відстеження прогресу (*Нове*, *У процесі*, *На перевірці*, *Завершено*).
- Аналітика: Статистика вчасно зданих робіт.

Рольова модель системи
1. Студент / Учень:
   - Перегляд переліку актуальних завдань і дедлайнів.
   - Зміна статусу завдання та прикріплення матеріалів/посилань на рішення.
   - Отримання нагадувань про терміни.

2. Викладач / Вчитель:
   - Створення та публікація завдань для окремих груп чи класів.
   - Встановлення дедлайнів, критеріїв оцінювання та прикріплення навчальних матеріалів.
   - Перевірка зданих робіт і зміна статусу на «Зараховано» / «Повернуто на доопрацювання».

Вимоги:
Повний перелік вимог і user stories знаходиться у папці `/requirements`:
`requirements/requirements.md` — 5 функціональних + 5 нефункціональних вимог.
`requirements/user-stories.md` — user stories з acceptance criteria.

Функціональні вимоги:
1.	Викладач створює, редагує та видаляє завдання для групи.
2.	Студент фільтрує та шукає завдання за предметом, статусом і пріоритетом.
3.	Зміна статусу завдання за ланцюжком: Нове → У процесі → На перевірці → Завершено.
4.	Прикріплення файлів (до 20 МБ) або посилань до завдання.
5.	Автоматичні email- та in-app сповіщення за 72, 24 і 2 години до дедлайну.
   
Нефункціональні вимоги:
1.	Швидкодія: Час відповіді ≤ 2 с при 500 одночасних користувачах.
2.	Безпека: Паролі bcrypt (cost ≥ 12), обмін даними через HTTPS (TLS 1.2+).
3.	Доступність (SLA):	Доступність ≥ 99,5 % на місяць (downtime ≤ 3,6 год/міс).
4.	Сумісність (UX):	Коректна робота у двох останніх версіях Chrome, Firefox, Safari, Edge; від 320 px.
5.	Локалізація:	Підтримка української та англійської мов без перезавантаження сторінки.

User Stories:
1. — Студент бачить список активних завдань, відсортованих за дедлайном.
2. — Викладач створює та публікує завдання для групи.
3. — Студент отримує нагадування про наближення дедлайну.
4. — Студент прикріплює розв'язання і переводить завдання на перевірку.
